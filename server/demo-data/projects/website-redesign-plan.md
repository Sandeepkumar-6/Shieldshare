# Website redesign plan

Owner: Marcus. Status: approved for October. Acme Studio is a fictional demo company.

## Why
The current site explains what we do but not how we work. Prospective clients ask the same
three questions on every intro call: how long projects take, how reviews work and how files
are shared. The redesign answers those questions on the page.

## Goals
1. A clear services page with typical timelines for each service.
2. Three case studies with before and after screenshots and the client's own words.
3. A "how we work" page that explains reviews, approvals and secure file sharing.
4. Load in under two seconds on mobile, and pass an accessibility review.

## Structure
- Home: one sentence on what we do, three case studies, contact.
- Services: design sprints, portal development, content migration, retainers.
- Work: case studies, filterable by industry.
- How we work: process, tools, file sharing with expiring links.
- About and contact.

## Design notes
- Keep the existing colour palette, reduce it to two accents.
- Real photography of the studio, no stock images.
- Every page must work without JavaScript for the core content.

## Launch checklist
- Redirects from the old URLs are tested.
- Analytics configured without third-party trackers.
- Contact form tested end to end.
